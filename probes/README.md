# Post-hoc robustness probes

All 12 solutions passed 100% of the hidden test suites, so these extra probes were written afterwards to look for differences the main suites could not see. They are derived from the task specs (not from any model's code), but because they were written after the main run they are reported separately and are NOT part of the primary score.

Timing probes are measurements, not pass/fail checks.
